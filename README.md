# Embedded Machine Monitor

A C/C++ embedded systems project built around a Raspberry Pi Pico W
and Raspberry Pi.

The goal is to develop a system that monitors the operating condition
of a small physical device using sensors and embedded firmware.

## Current Progress

- Configured Raspberry Pi as development machine
- Installed Pico C/C++ SDK
- Built and flashed Pico W firmware
- Controlled the onboard LED
- Read a physical push button using GPIO
- Used button input to control the onboard LED
